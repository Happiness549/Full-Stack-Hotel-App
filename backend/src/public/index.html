Endpoints

  • POST /api/hotels - Create a new hotel (Admin only)
  • GET /api/hotels - Get all hotels
  • GET /api/hotels/:id - Get a specific hotel by ID
  • PUT /api/hotels/:id - Update a specific hotel by ID (Admin only)
  • DELETE /api/hotels/:id - Delete a specific hotel by ID (Admin only)
  • POST /api/reviews/:hotelId - Create a review for a specific hotel (Authenticated users only)
  • PUT /api/reviews/:id - Update a specific review by ID (Authenticated users only)
  • GET /api/reviews - Get all reviews (Authenticated users only)
  • GET /api/reviews/:id - Get a specific review by ID (Authenticated users only)
  • DELETE /api/reviews/:id - Delete a specific review by ID (Authenticated users only)
  • POST /api/notifications - Create a new notification (Admin only)
  • PUT /api/notifications/:id - Mark a notification as read (Authenticated users only)
  • DELETE /api/notifications/:id - Delete a specific notification by ID (Authenticated users only)
